### cap002 — Validate generated vars + extend _validate_vars to environment fields (2026-02-28)

- `_load_vars` now raises `CutipError` when a `generated:` var has an empty path value

- `_validate_vars` now checks `spec.environment` values in addition to mount source/target
  so empty required vars are caught before any container backend is contacted
